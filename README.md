## ⚡ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Anubhav2321/portfolio-website.git
```

### 2. Open the Project

```bash
cd portfolio-website
```

### 3. Run Locally

Since this is a static portfolio website, you can simply open:

```text
index.html
```

in your browser.

For a better development experience, use **VS Code Live Server**.
